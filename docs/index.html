rhkd HomeKit Architecture

How rhkd, the native HomeKit daemon for Thingino cameras, turns raptor's shared-memory rings into live view, snapshots, talk-back, motion and HomeKit Secure Video. Tested on the Wyze Cam v3 (T31X) and v4 (T41NQ).

Development line. This page shows rhkd 0.9.7. The released code in this repository is 0.7.7; the aux live stream, two live viewers, talk-back with the echo-cancellation switch and recording send-pacing arrive with the next release. Source on GitHub.

One process, no bridge

rhkd is a static mipsel binary built on Apple's HomeKitADK with mbedTLS. Home talks to the camera directly; nothing like Scrypted or Homebridge runs in between.

Encoders only run when watched

The aux video stream and the audio2/audio3 outputs start when rhkd opens their ring and stop a few seconds after the last reader leaves.

No transcoding on the camera

Live view takes Opus from audio2, recordings take AAC from audio3. The Opus to AAC fallback is only needed when rad offers no AAC output, and can be compiled out (TRANSCODE=0).

Per camera

v4 (T41NQ): main 2560×1440, aux up to 1920×1080 at 2.5 Mbit/s. v3 (T31X): main 1920×1080 capped at 2 Mbit/s, aux up to 1280×720.
